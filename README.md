# Ozea Dental Clinic — Dr. Youssef Nasser

Website for **Ozea Dental Clinic** (Dr. Youssef Nasser — dental implants and
maxillofacial surgery, Nasr City, Cairo). A React site, pre-rendered to static
HTML at build time in four languages. It includes WhatsApp enquiries, an
interactive 3D face and jaw studio, treatment pages, doctor profiles, a services
hub and a contact page.

**Live:** https://ozeamaxillofacialclinic.com

## Stack

| Layer    | Choice |
|----------|--------|
| Build    | Vite 7 |
| UI       | React 19 + TypeScript |
| Styling  | Tailwind CSS 3 + shadcn/ui (Radix primitives) |
| Motion   | Framer Motion |
| Routing  | React Router 7 |
| Hosting  | Cloudflare Pages |

## Local development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # type-check, bundle, then pre-render every page into dist/
npm run serve:dist  # serve dist/ the way Cloudflare Pages does (clean URLs, real 404)
npm run lint
```

Node.js 20 or newer.

### Case photographs

Drop new masters in `brand/cases/`, add them to `scripts/prep-case-art.mjs` and to the
list in `src/lib/cases.ts`, then run `npm run build:case-art`. The script writes two
widths of WebP plus a typed manifest with each image's size and blurred preview; the
captions live in `src/lib/copy/{en,ar}.ts` under `cases.items`, keyed by slug.

### Editing clinic details

Phone numbers, WhatsApp link, address, opening hours, Instagram handle, and the
Google Maps link/embed all live in [`src/lib/site.ts`](src/lib/site.ts). Change
them there — every section reads from that module.

## Search, languages and pre-rendering

The site is built to be read by search engines and AI assistants, not only by
browsers:

- **Every page is real HTML.** `npm run build` renders each route in each
  language and writes it to `dist/` (`index.html`, `ar.html`,
  `services/dental-implants.html`, …) with its own title, description,
  canonical, `hreflang` alternates and JSON-LD. The browser then hydrates it.
- **The language is the URL.** English is at `/`, Arabic at `/ar`, French at
  `/fr`, Russian at `/ru`. Always build internal links with `path()` from
  `useI18n()` so they stay in the visitor's language.
- **Structured data** comes from `src/lib/seo.ts`: the clinic
  (`Dentist`/`MedicalClinic`), each doctor, each treatment
  (`MedicalProcedure`), FAQs and breadcrumbs. Opening hours and map
  coordinates are left out until confirmed — set them in `CLINIC_FACTS`.
- **`sitemap.xml`, `llms.txt` and `llms-full*.txt`** are generated by the build
  from the same page list. Do not add them to `public/`.
- **Unknown URLs return a real 404** (`404.html`). There is no SPA fallback, so
  a page that should exist must be pre-rendered.

### Adding a treatment page

1. Add its id to `PAGE_IDS` in `src/lib/copy/pages/types.ts`. The type-check now
   fails until every language has copy for it.
2. Write the copy in `src/lib/copy/pages/{en,ar,fr,ru}-*.ts`.
3. Add an entry to `PAGES` in `src/lib/pages.ts` (path, artwork, clinicians,
   related pages) and an English topic in `TOPIC_EN`.

The route, the pre-rendered HTML, the sitemap entry, the structured data, the
footer link and the `llms.txt` line all follow from those three steps.

### Adding a language

Add the code to `Lang`, `LANGS`, `DIR`, `LANG_META` and `STAFF_LANG` in
`src/lib/copy/index.ts`, write `src/lib/copy/<code>.ts` and
`src/lib/copy/pages/<code>*.ts`, add `src/lib/copy/bundles/<code>.ts` and a
loader line in `src/lib/copy/bundle.ts`. The clinic consults in Arabic and
English; a language the team cannot answer in must say so (`ui.consultNote`).

### Medical review

The treatment pages are general patient information. Once the treating doctors
have read their pages, set `MEDICAL_REVIEW` in `src/lib/pages.ts` to the review
date: the pages then show a "medically reviewed" line and declare it in their
structured data.

## Deployment

Cloudflare Pages, direct upload from a local build:

```bash
npm run build
npx wrangler pages deploy dist --project-name=dryoussefnasser --branch=main
```

`dist/` is fully static: one `.html` file per page, which Cloudflare Pages serves
at the matching clean URL (`ar/services/veneers.html` → `/ar/services/veneers`),
and `404.html` for everything else. `public/_headers` sets immutable caching on
fingerprinted assets plus baseline security headers.

In the Cloudflare dashboard, keep **Block AI bots** off and add a redirect rule
from `www.ozeamaxillofacialclinic.com` to the bare domain — neither can be set
from this repository.
